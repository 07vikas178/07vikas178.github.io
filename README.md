# Vikas V - Portfolio

Personal portfolio of **Vikas V**, a Computer Science graduate and aspiring full-stack developer based in Bangalore, looking for Software Developer opportunities.

Built with [Gatsby](https://www.gatsbyjs.org/).

## Installation & Set Up

1. Install the Gatsby CLI

   ```sh
   npm install -g gatsby-cli
   ```

2. Install and use the correct version of Node using [NVM](https://github.com/nvm-sh/nvm)

   ```sh
   nvm install
   ```

3. Install dependencies

   ```sh
   yarn
   ```

4. Start the development server

   ```sh
   npm start
   ```

## Building and Running for Production

1. Generate a full static production build

   ```sh
   npm run build
   ```

2. Preview the site as it will appear once deployed

   ```sh
   npm run serve
   ```

## Where to edit content

- `src/config.js`: email, social links, and nav links
- `gatsby-config.js`: site title, description, and URL
- `src/components/sections/`: hero, about, and contact text
- `content/jobs/`: education entries
- `content/featured/`: featured projects
- `src/components/sections/projects.js`: skills
